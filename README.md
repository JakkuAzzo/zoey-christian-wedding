# Zoey & Christian's wedding

A static, mobile-friendly wedding website ready for GitHub Pages. Open `index.html` locally or serve this directory with any static web server. All paths are relative so the site works at a GitHub Pages project URL.

## Content to confirm

The reference site and supplied screenshots contain conflicting ceremony and schedule times. The site intentionally does not publish a time until the couple confirms it. Venue addresses come from the reference site. Confirm travel, accommodation and other details before sharing widely.

## Future RSVP and Firebase

RSVPs are not yet active and no guest data is collected. Once requirements and a Firebase project are available, design the RSVP flow and security rules together. Do not store guest data in the repository or rely on client-side hiding for security. The current site has no Firebase configuration or credentials.

## GitHub Pages

Push this repository to GitHub, then enable Pages in **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save. GitHub will provide the published URL.
